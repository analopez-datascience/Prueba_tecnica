# SQL Prueba Técnica

Prueba técnica SQL realizada en PostgreSQL sobre un modelo de e-commerce.

## 📁 Estructura

- `create_insert.sql` → creación de tablas e inserción de datos de prueba
- `ana_lopez_prueba_tecnica.sql` → resolución de las consultas SQL

## 🧱 Tablas utilizadas

- `customers`
- `products`
- `orders`
- `orderlines`

## 💡 Notas

- Se incluyen clientes sin pedidos y productos sin ventas para cubrir distintos casos de uso.
- Las consultas están orientadas a PostgreSQL.
